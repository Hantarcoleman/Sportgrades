## אפריל 2026

### [2026-04] — גרסה 1.0 — שחרור ראשוני

**SportGrade (pe-grading-app.html):**
- מנועי מבחן חי: ביפ, ריצות ארוכות, מטרונום, טיימר
- כל מבחני הכוח + ריצה לפי מחוון תשפ"ו
- מחציות א' + ב' עם שיפור/ירידה בצבע
- קבוצה אקראית
- Sidebar עם pin
- מדריך למורה
- עריכת קבוצה (view מלא + העברת תלמיד)
- ייצוא Excel
- ניהול אורחים בין קבוצות

**TourneyGrade (משולב בתוך pe-grading-app.html):**
- ליגה + נוקאאוט, 3-16 קבוצות
- הלוך וחזור (legs)
- כובשים ומבשלים לפי שורות + שערים עצמיים
- טבלה + FORM + H2H + פרוטוקול
- ייצוא PDF/CSV/iCal
- QR Code
- ריבוי טורנירים
