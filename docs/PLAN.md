## שלב 1 — Git (גיבוי וניהול גרסאות)

**מטרה:** כל שינוי מוגן — אפשר לחזור אחורה תמיד.

**מה צריך לעשות (פעם אחת):**
1. להוריד Git: https://git-scm.com/download/win
2. להוריד GitHub Desktop: https://desktop.github.com
3. לפתוח חשבון GitHub: https://github.com
4. ליצור repository בשם `sportgrade`
5. לגרור את תיקיית `sportgrade-project` לתוכו

**מה מרוויחים:**
- כל גרסה שמורה לנצח
- אפשר לראות מה השתנה ומתי
- בסיס להעלאה לאינטרנט בעתיד

**קושי:** נמוך מאוד — ממשק גרפי, ללא שורת פקודה.

---

## שלב 2 — Supabase (סנכרון בין מכשירים)

**מטרה:** כל מורה יכנס מכל טלפון/מחשב ויראה את הנתונים שלו.

**מה זה Supabase:**
שירות ענן שמחזיק את הנתונים. חינמי עד 50 משתמשים.
אתר: https://supabase.com

**מבנה הטבלאות:**

```
teachers         ← מורים
─────────────────────────────
id               מזהה ייחודי
email            אימייל
name             שם מלא
school           בית ספר
created_at       תאריך הצטרפות
is_active        פעיל/מושבת (true/false)

groups           ← קבוצות לימוד
─────────────────────────────
id
teacher_id       → מי יצר את הקבוצה
name             שם הקבוצה
grade            שכבה (ז/ח/ט...)
semester_a_data  נתוני מחצית א' (JSON)
semester_b_data  נתוני מחצית ב' (JSON)
created_at

tournaments      ← טורנירים
─────────────────────────────
id
teacher_id
name
data             כל נתוני הטורניר (JSON)
created_at
```

**מה צריך לשנות בקוד:**
- כ-200 שורות קוד בקובץ הראשי
- במקום לשמור ב-localStorage → שולח ל-Supabase
- הוספת מסך כניסה (אימייל + סיסמה)

**זמן משוער:** 2-3 שבועות עבודה עם Claude

---

## שלב 3 — ניהול מורים (לוח בקרה)

**מטרה:** אתה רואה את כל המורים, שולט על גישה.

**מה תכלול לוח הבקרה:**
```
מורים רשומים: 23 / 50
─────────────────────────────────────
שם          בית ספר    כניסה אחרונה   פעולות
דוד לוי     אורט       היום 14:32    [השבת] [מחק]
שרה כהן     עמל        אתמול         [השבת] [מחק]
...
```

**בקרת כמות משתמשים:**
- גבול מוגדר בקוד (50 / 100 / כל מספר)
- מייל אזהרה כש-80% מהגבול מלא
- חסימה אוטומטית בהגעה לגבול
- מייל אליך כשמישהו מנסה להירשם אחרי הגבול

**קוד הזמנה:**
- מורה חדש מזין קוד שאתה נתת לו
- ללא קוד → לא מורשה
- אתה יכול לשנות את הקוד בכל עת

**זמן משוער:** שבוע נוסף
