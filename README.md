# SportGrade 🏃
**מערכת הערכה בחינוך גופני**

---

## איך לפתוח את האפליקציה

1. פתח את התיקייה `client`
2. לחץ פעמיים על `pe-grading-app.html`
3. האפליקציה נפתחת בדפדפן

---

## מבנה התיקיות

```
sportgrade-project/
│
├── client/                    ← האפליקציה עצמה
│   ├── pe-grading-app.html    ← הקובץ הראשי (פתח את זה)
│   ├── tournament-manager.html ← מנהל טורנירים (גיבוי)
│   └── assets/                ← תמונות, אייקונים (בעתיד)
│
├── docs/                      ← תיעוד
│   ├── STATUS.md              ← מצב הפרויקט
│   ├── PLAN.md                ← תוכנית העבודה
│   └── CHANGELOG.md           ← יומן שינויים
│
├── README.md                  ← המסמך הזה
└── .gitignore                 ← קבצים שלא שומרים ב-Git
```

---

## מצב נוכחי

- ✅ האפליקציה עובדת מקומית (בלי אינטרנט)
- ✅ שומרת נתונים בדפדפן (localStorage)
- ⏳ בעתיד: מעבר ל-Supabase (סנכרון בין מכשירים)
- ⏳ בעתיד: כניסה עם סיסמה לכל מורה
